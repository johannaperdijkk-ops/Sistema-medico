# Medical Appointment System

## Description
This project is a backend prototype for a medical appointment system. It includes authentication, doctor listing, appointment management, and a simulated notification service.

## Features
- User login
- Doctor list retrieval
- Appointment creation
- Appointment update
- Appointment deletion

## Project Structure
- controllers: request handling
- routes: API endpoints
- services: business logic
- models: data structure
- data: mock data for testing
